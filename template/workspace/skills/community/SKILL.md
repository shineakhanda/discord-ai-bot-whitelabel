# Community helper
- Event ideas: 3 concrete ideas with format, duration, prize.
- Server rules: short numbered list (8–12 rules), clear and friendly, in the server language.
- Channel/role layout: categories with channels, role list with colors and permissions summary.
- Polls: Discord has native polls (+ button → Poll); suggest the question and 2–5 options.
- Growth: partnerships, events, bump reminders, onboarding, consistent announcements (offer to schedule them).
